## 🚀 Projects

### 🌾 Seed Farm (컴퓨터 비전 기반 스마트팜 자율 대응 시스템)
> **기간:** 2026.03.31 ~ 2026.04.27
> **Organization을 활용해 Frontend, Backend, ML 파트를 분리하고 협업한 종합 AI 스마트팜 시스템입니다.**
* **[Frontend](https://github.com/Team-2-Final/Frontend)**: React 기반 실시간 모니터링 대시보드 및 아키텍처 설계
  * AI 모델 판별 결과 연동 시, 결과 유형(Result Type) 바로 아래에 심각도(Severity) 지표가 직관적으로 보이도록 UI 레이아웃 최적화 및 데이터 시각화 구현
  * 실제 장비가 없는 환경을 극복하기 위해 Python 기반 시뮬레이터를 직접 제작하여, 대용량 이미지의 실시간 스트리밍 데이터 흐름 재현 및 렌더링 최적화
* **[Backend](https://github.com/Team-2-Final/Backend)**: FastAPI, MongoDB, Oracle을 연동한 효율적인 데이터 관리 및 안정적인 API 통신 구조 설계
* **[ML](https://github.com/Team-2-Final/ML)**: PyTorch를 활용한 멀티뷰 기반 생육 추론 및 착색 비율 분석 모델 구축을 통해 이상 징후 자동 대응 기능 고도화

### 🏭 반도체 패키징 공정 MES
> **기간:** 2026.01.15 ~ 2026.02.10
> **[레포지토리 바로가기](https://github.com/kurecat/mes_final_project_total)**
> **반도체 패키징 공정의 데이터 추적 및 생산 관리를 돕는 통합 지능화 웹 서비스입니다.**
* **Role**: Main FrontEnd / Sub BackEnd
* 대용량 데이터 렌더링 최적화에 집중하며, 유지보수가 용이한 재사용 가능 React UI 컴포넌트 설계
* Spring Boot와 JPA를 활용한 백엔드 서버 구축 및 프론트엔드와의 안정적인 API 통신 로직 구현
* **Tech Stack**: React, Spring Boot, JPA, MySQL, C#
