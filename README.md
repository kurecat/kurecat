## 🚀 Projects

### 🌾 Seed Farm (스마트팜 자율 대응 자동화 시스템)
> **기간:** 2026.03.31 ~ 2026.04.27
> **Organization을 활용해 Frontend, Backend, ML 파트를 분리하고 협업한 AI 스마트팜 시스템입니다.**
* **[Frontend](https://github.com/Team-2-Final/Frontend)**: React 기반 실시간 모니터링 대시보드 및 아키텍처 설계
  * 실제 장비가 없는 환경을 위해 **Python 기반 시뮬레이터**를 직접 제작하여 실시간 스트리밍 데이터 흐름 구현
  * 심각도(Severity) 및 결과 유형(Result Type) 중심의 데이터 시각화 및 컴포넌트 레이아웃 최적화
* **Backend**: FastAPI, MongoDB, Oracle 연동을 통한 데이터 관리 구조 구축
* **ML**: 멀티뷰 기반 생육 추론 및 착색 비율 분석 모델 구축 (PyTorch)
